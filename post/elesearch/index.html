技术栈与依赖安装

所用技术栈详解

本工具采用Python作为开发语言，核心技术栈围绕“GUI交互+网络请求+数据处理+系统适配”展开，各技术模块各司其职、协同工作，确保工具稳定、高效运行，以下是各技术的详细解析：

  • GUI框架：tkinter + ttk（内置，无需额外安装）

核心作用：构建工具的可视化界面，实现用户与工具的交互。tkinter是Python内置的GUI框架，轻量、易上手，无需额外安装依赖，适配Windows系统，完美满足校园工具“免配置”的核心需求；ttk是tkinter的扩展模块，提供更美观的组件（如组合框、按钮、框架），解决了原生tkinter组件样式单一的问题，同时支持主题切换，为浅色/深色双主题功能提供技术支撑。

关键应用：页面布局（分区域设计查询区、结果区、按钮区）、组件绑定（下拉框选择、按钮点击事件、主题切换触发）、文本显示（电费信息、操作提示），所有用户可见的交互元素均基于此实现。

  • 网络请求：requests 核心作用：模拟浏览器发送HTTP请求，获取校园电费查询网页的内容。校园电费系统为网页端，无公开API，因此需要通过requests模拟用户登录、查询的操作，获取页面中的电费数据。

关键应用：建立会话（Session）保持请求状态，避免重复登录；设置请求头（User-Agent）模拟浏览器，防止被服务器拦截；发送GET请求获取网页视图状态（VIEWSTATE），发送POST请求提交楼号、房间号等查询参数，实现电费数据的抓取。

  • 网页解析：BeautifulSoup4 核心作用：解析requests获取的网页HTML内容，提取出需要的电费数据。网页返回的是杂乱的HTML代码，通过BeautifulSoup4的标签定位、文本提取功能，筛选出电费数值、错误提示等关键信息。

关键应用：定位网页中的隐藏域（__VIEWSTATE、__EVENTVALIDATION），用于构造POST请求参数；定位电费显示表格（yongdianGrid），提取普通电费、空调电费的数值；定位错误提示标签（txtErr），捕获“房间号错误”“无数据”等异常情况，提升用户体验。

  • 数据处理：json + pandas 核心作用：实现数据的存储、读取和统计分析。json用于轻量级数据存储（如房间信息、查询历史、系统设置），将数据以JSON格式写入本地文件，便于读取和修改；pandas用于复杂数据统计（如日均用电量、月度账单），处理大量查询历史数据，高效计算用电相关指标。

关键应用：json存储默认房间、多房间列表、低电量阈值等配置信息，实现“重启工具保留配置”；pandas读取历史查询数据，按日期、月份分组，计算日均用电量、月度总用电量，为数据可视化和用电统计功能提供数据支撑。

  • 可视化图表：matplotlib 核心作用：将查询历史数据转化为直观的柱状图，方便用户查看用电趋势。matplotlib是Python主流的数据可视化库，支持多种图表类型，此处用于生成12小时时段用电柱状图，清晰展示不同时段的用电量差异。

关键应用：设置中文字体（SimHei），解决图表中文乱码问题；提取有效历史数据，按12小时时段分组（06:00-18:00、18:00-次日06:00），计算各时段用电量；绘制柱状图，添加数值标签、标题、坐标轴说明，提升图表可读性，同时将图表嵌入Tkinter界面，实现“点击按钮查看图表”的交互。

  • 系统功能：threading + winsound + pystray

  • threading（多线程）：核心用于实现“后台自动查询”功能。开启独立线程运行自动查询逻辑，避免阻塞主线程（GUI界面），确保用户在使用工具其他功能时，自动查询仍能后台静默运行，每12小时执行一次查询操作。

  • winsound（系统提示音）：实现低电量提醒的声音反馈，当电费低于阈值时，播放不同频率、时长的提示音（普通低电800Hz/500ms，紧急低电1000Hz/800ms），强化提醒效果。

  • pystray（系统托盘）：实现工具“最小化到托盘”功能，关闭窗口时不退出程序，仅最小化到系统托盘，点击托盘图标可重新显示窗口、退出程序，提升工具的实用性和后台运行体验。

  • 快捷键：keyboard 核心作用：实现快捷键快速查询功能，用户无需点击按钮，通过预设快捷键（如Ctrl+Q）即可触发电费查询，提升操作效率。

关键应用：绑定快捷键事件，监听用户按键操作，当检测到预设快捷键时，自动执行查询逻辑，返回电费结果，适配用户快速操作的需求。

核心功能技术实现详解

一、电费查询核心逻辑（最核心模块）

电费查询功能的核心是“模拟浏览器请求+网页解析”，分为两个关键步骤：获取网页视图状态、提交查询参数并解析结果，具体实现逻辑如下：

  1. 获取网页视图状态（VIEWSTATE） 校园电费查询网页采用ASP.NET开发，这类网页会通过隐藏域（__VIEWSTATE、__VIEWSTATEGENERATOR、__EVENTVALIDATION）存储页面状态信息，提交查询请求时必须携带这些参数，否则请求会被服务器拒绝。

实现逻辑：通过requests.get()请求电费查询首页，使用BeautifulSoup4解析页面HTML，定位到三个隐藏域的input标签，提取其value值，封装为字典，用于后续POST请求的参数。

异常处理：若请求超时、页面解析失败，返回“获取页面失败”提示，避免程序崩溃。

  1. 提交查询参数并解析结果 构造POST请求参数，包含上一步获取的视图状态参数，以及用户选择的楼号（转换为校园系统对应的编码）、房间号，还有查询按钮的触发参数（chaxun=查询）。

发送POST请求后，解析返回的网页内容：优先定位错误提示标签，若存在错误文本（如“房间号不存在”），直接返回错误信息；若无错误，定位电费显示表格，提取表格中的电费数值，转换为浮点数（便于后续低电量判断），若解析失败则返回“解析失败”。

关键优化：区分普通电费和空调电费，通过楼号编码映射表（BUILDING_MAP、AIR_CONDITIONING_MAP），根据用户选择的楼号，自动匹配对应的空调电费查询编码，实现双电费同步查询。

二、自动后台监测与低电量提醒

该功能依赖多线程（threading）实现后台运行，结合低电量阈值判断、系统提示音（winsound）、多平台推送，形成完整的提醒机制，具体实现如下：

  1. 后台自动查询线程 开启独立的守护线程（daemon=True），线程内部循环执行查询逻辑，每次查询完成后休眠12小时（43200秒），实现“每12小时自动查询一次”。 关键细节：守护线程会随主线程（GUI界面）退出而退出，避免程序退出后线程仍在后台运行；使用root.after(0, 函数)更新GUI界面的电费结果，避免多线程直接操作GUI组件导致的线程安全问题。

  2. 双重低电量提醒逻辑 读取系统设置中的低电量阈值（默认10元）和紧急充电阈值（默认5元），每次查询后判断普通电费数值：

  • 当电费低于低电量阈值时，播放提示音，弹出弹窗提醒，同时触发多平台推送，告知用户“电费过低”；

  • 当电费低于紧急充电阈值且未触发过紧急提醒时，播放更长时长、更高频率的提示音，弹出紧急弹窗，触发多平台推送，告知用户“尽快充电”；

  • 当电费回升至紧急充电阈值以上时，重置紧急提醒状态，避免重复提醒。

三、多平台消息推送实现

接入微信、钉钉、QQ机器人，实现低电量提醒的远程推送，让用户不在电脑前也能收到提醒，具体实现逻辑如下：

  • 微信推送：使用企业微信机器人webhook，用户需提前获取机器人的key，工具通过requests.post()向微信webhook接口发送POST请求，携带提醒文本，实现微信消息推送；

  • 钉钉推送：使用钉钉机器人webhook，用户获取机器人的url后，工具通过requests.post()发送POST请求，格式与微信推送类似，实现钉钉消息推送；

  • QQ推送：使用Qmsg推送接口，用户获取推送key后，工具通过requests.get()发送请求，携带提醒文本，实现QQ消息推送；

关键优化：所有推送接口均添加超时处理（timeout=5秒），若推送失败不影响工具主功能运行，同时支持用户在设置中填写/修改推送密钥，灵活开启/关闭推送功能。

四、数据管理与可视化

数据管理核心是“本地文件存储”，数据可视化核心是“历史数据统计+图表生成”，两者结合实现用电情况的直观展示和数据留存，具体实现如下：

  1. 数据本地存储 在工具运行目录下创建data文件夹，用于存储4类核心数据，均以JSON格式保存，便于读取和修改：

  • default_rooms.json：存储默认房间信息，用户首次查询后自动保存，下次打开工具无需重复输入；

  • electric_history.json：存储所有房间的查询历史，包含查询时间、普通电费、空调电费、月份信息，用于后续统计和可视化；

  • settings.json：存储系统设置，包括低电量阈值、紧急充电阈值、主题设置、推送密钥等；

  • rooms.json：存储多房间列表，用户可批量添加房间，一键切换查询。

关键优化：添加异常处理，若文件损坏或不存在，自动创建默认文件，避免工具因文件问题无法运行。

  1. 数据可视化实现 基于matplotlib实现12小时时段用电柱状图，核心步骤如下：

  2. 读取当前房间的查询历史数据，筛选出有效数据（排除“无数据”“解析失败”等异常记录）；

  3. 按日期和时段分组，将一天分为两个12小时时段（06:00-18:00、18:00-次日06:00），计算每个时段的用电量（上一时段电费 - 当前时段电费，确保数值非负）；

  4. 配置matplotlib图表样式，设置中文字体、柱状图颜色、数值标签，生成图表标题和坐标轴说明；

五、GUI界面优化与系统适配

围绕“用户体验”优化GUI界面，实现主题切换、系统托盘、快捷键等功能，同时适配EXE打包，确保无Python环境也能运行，具体实现如下：

  1. 双主题切换 通过ttk.Style()配置不同主题的样式，浅色主题采用浅灰色背景、深蓝色按钮，深色主题采用深灰色背景、浅灰色按钮，用户可通过下拉框选择主题，选择后自动保存到settings.json，下次打开工具自动加载对应主题。

关键细节：切换主题时，重新配置根窗口和所有组件的样式，确保界面所有元素同步切换，无样式错乱。

  1. 系统托盘与窗口关闭逻辑 使用pystray创建系统托盘图标，图标采用简单的文字绘制（“电费”），托盘菜单包含“显示窗口”和“退出程序”两个选项；关闭窗口时，弹出弹窗让用户选择“退出程序”或“最小化到托盘”，避免误操作导致工具退出。

  2. EXE打包适配 通过判断sys.frozen属性，区分工具运行环境（Python脚本环境、EXE打包环境），动态获取工具运行目录：EXE环境下，运行目录为EXE文件所在目录；脚本环境下，运行目录为脚本文件所在目录。

六、异常处理与稳定性优化

工具在关键模块均添加了异常处理，确保运行稳定，避免因异常情况导致程序崩溃，主要异常处理场景如下：

  • 网络异常：请求网页时添加超时处理，若网络中断、服务器无响应，返回明确的错误提示，不崩溃；

  • 数据解析异常：若网页结构变化、电费数值格式异常，返回“解析失败”提示，同时不影响历史数据存储；

  • 文件操作异常：读取、写入本地文件时，捕获文件不存在、权限不足等异常，自动创建默认文件或提示用户；

  • 用户操作异常：用户未选择楼号、未输入房间号时，弹出提示，阻止无效查询操作。

    try:

                return json.load(f)
    except:
        pass

def save_history(building, room, normal_ele, ac_ele):
    history = load_history()
    key = f"{building}_{room}"
    now = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    if key not in history:
        history[key] = []
    if history[key] and now[:-3] in history[key][-1]["time"]:
        return
    
    history[key].append({
        "time": now,
        "normal": normal_ele,
        "air": ac_ele,
        "month": now[:7]
    })
    with open(HISTORY_FILE, "w", encoding="utf-8") as f:
        json.dump(history, f, ensure_ascii=False)

    if not key: return

# ===================== 查询 =====================
def get_view_state(session):
    url = "http://dfcz.upc.edu.cn/ShiYou/Default.aspx?code=dx9VGxG4yEHVLLkeJm5-8F5Ff_n6tmlM1hV2rfzNYL0&state=STATE#"
    try:
        res = session.get(url, headers={"User-Agent": "Mozilla/5.0"}, timeout=10)
        soup = BeautifulSoup(res.text, "html.parser")
        return {
            "__VIEWSTATE": soup.find("input", id="__VIEWSTATE")["value"],
            "__VIEWSTATEGENERATOR": soup.find("input", id="__VIEWSTATEGENERATOR")["value"],
            "__EVENTVALIDATION": soup.find("input", id="__EVENTVALIDATION")["value"],
        }
    except:
        return None

def query(building_val, room):
    if not building_val: return "无数据"
    session = requests.Session()
    vs = get_view_state(session)
    if not vs: return "获取页面失败"
    url = "http://dfcz.upc.edu.cn/ShiYou/Default.aspx?code=dx9VGxG4yEHVLLkeJm5-8F5Ff_n6tmlM1hV2rfzNYL0&state=STATE#"
    data = {**vs, "lou": building_val, "yonghu": room, "chaxun": "查询"}
    try:
        res = session.post(url, data=data, headers={"User-Agent": "Mozilla/5.0"}, timeout=10)
        soup = BeautifulSoup(res.text, "html.parser")
        err = soup.find("span", id="txtErr")
        if err and err.text.strip(): return err.text.strip()
        table = soup.find("table", id="yongdianGrid")
        if not table: return "无数据"
        rows = table.find_all("tr")
        if len(rows) >= 2:
            cols = rows[1].find_all("td")
            if len(cols) >= 2:
                val = cols[1].text.strip()
                try: return float(val)
                except: return val
        return "解析失败"
    except Exception as e:
        return str(e)

# ===================== 自动查询 =====================
def auto_query_thread(building_val, room, ac_val, result_text, root):
    settings = load_settings()
    warn_val = settings.get("warn_value", 10)
    charge_warn = settings.get("charge_warn", 5)
    last_charge_alert = False
    
    while True:
        try:
            normal_ele = query(building_val, room)
            ac_ele = query(ac_val, room) if ac_val else "无空调"
            save_history(building_val, room, normal_ele, ac_ele)
            
            root.after(0, lambda: update_result(result_text, normal_ele, ac_ele))
            
            try:
                ele_num = float(normal_ele)
                if ele_num < warn_val:
                    winsound.Beep(800, 500)
                    msg = f"房间{room}电费过低！当前：{ele_num}元"
                    root.after(0, lambda: messagebox.showwarning("提醒", msg))
                    send_all_alert(msg)
                if ele_num < charge_warn and not last_charge_alert:
                    last_charge_alert = True
                    msg = f"房间{room}电量极低，请尽快充电！当前：{ele_num}元"
                    winsound.Beep(1000, 800)
                    root.after(0, lambda: messagebox.showwarning("充电提醒", msg))
                    send_all_alert(msg)
                if ele_num >= charge_warn:
                    last_charge_alert = False
            except:
                pass
        except:
            pass
        time.sleep(43200)

def update_result(result_text, normal_ele, ac_ele):
    result_text.delete(1.0, tk.END)
    result_text.insert(tk.END, f"普通电费：{normal_ele}\n")
    result_text.insert(tk.END, f"空调电费：{ac_ele}\n")
    result_text.insert(tk.END, f"更新时间：{datetime.now().strftime('%Y-%m-%d %H:%M:%S')}")

# ===================== 托盘图标 =====================
def create_icon(root):
    def quit_window(icon, item):
        icon.stop()
        root.destroy()

    def show_window(icon, item):
        icon.stop()
        root.after(0, root.deiconify)

    def hide_window():
        root.withdraw()
        image = Image.new('RGB', (64, 64), color=(255,255,255))
        draw = ImageDraw.Draw(image)
        draw.text((10,20), '电费', fill='blue')
        menu = (item('显示', show_window), item('退出', quit_window))
        icon = pystray.Icon("electricity", image, "宿舍电费查询工具", menu)
        icon.run()

    # 关闭弹窗选择
    def on_close():
        result = messagebox.askquestion("退出程序", "你想做什么？\n\n是(Y)：退出程序\n否(N)：最小化到托盘", icon="question")
        if result == "yes":
            root.destroy()
        else:
            hide_window()

    root.protocol('WM_DELETE_WINDOW', on_close)

                "wechat_key": wechat_var.get(),
                "dingtalk_url": ding_var.get(),
                "qq_key": qq_var.get(),
                "theme": theme_var.get()
            })
            messagebox.showinfo("成功", "保存成功")
            set_win.destroy()
        ttk.Button(set_win, text="💾 保存设置", command=save).pack(pady=10)

    # 历史
    def show_history():
        key = f"{BUILDING_MAP[building_var.get()]}_{room_entry.get().strip()}"
        history_text.delete(1.0, tk.END)
        for item in load_history().get(key, [])[-15:]:
            history_text.insert(tk.END, f"{item['time']} | 普通：{item['normal']} | 空调：{item['air']}\n")

    # 添加房间
    def add_room():
        b = building_var.get()
        r = room_entry.get().strip()
        if not b or not r:
            messagebox.showwarning("提示", "请填写完整")
            return
        rs = load_rooms()
        for item in rs:
            if item["building"] == b and item["room"] == r:
                messagebox.showinfo("提示", "房间已存在")
                return
        rs.append({"building": b, "room": r})
        save_rooms(rs)
        load_room_list()
        messagebox.showinfo("成功", "添加成功")

    def switch_room(event):
        txt = room_var.get()
        if not txt:
            return
        # 拆分 楼栋 + 房间号
        parts = txt.split(" ")
        if len(parts) < 2:
            return
        
        b = " ".join(parts[:-1])  # 楼栋（支持多词）
        r = parts[-1]             # 房间号（最后一段）
        
        building_var.set(b)
        room_entry.delete(0, tk.END)  # 先清空！修复核心BUG
        room_entry.insert(0, r)
        do_query()

    # 月度账单
    # 月度账单（终极修复版：支持带“度”、算空调、去重、数据少也正常显示）
    def show_month_bill():
        build_name = building_var.get()
        room = room_entry.get().strip()
        if not build_name or not room:
            messagebox.showwarning("提示", "请选择房间")
            return

        key = f"{BUILDING_MAP[build_name]}_{room}"
        hist = load_history().get(key, [])
        if not hist:
            messagebox.showwarning("提示", "无历史数据")
            return

        # 1. 清洗数据：去掉“度”、转数字、去重、按时间排序
        valid = []
        last_normal = None
        last_air = None

        for item in hist:
            try:
                # 时间
                dt = datetime.strptime(item["time"], "%Y-%m-%d %H:%M:%S")
                
                # 普通用电（去掉“度”）
                n_str = str(item["normal"]).replace("度", "").strip()
                normal = float(n_str)
                
                # 空调用电
                air = 0.0
                air_str = str(item["air"]).replace("度", "").strip()
                if air_str.replace(".","").isdigit():
                    air = float(air_str)

                # 去重：和上一条完全一样就跳过
                if normal == last_normal and air == last_air:
                    continue
                last_normal = normal
                last_air = air

                valid.append((dt, normal, air))
            except:
                continue

        if len(valid) < 2:
            messagebox.showwarning("提示", "有效记录不足，无法计算账单")
            return

        # 2. 按月累加用电量（普通 + 空调）
        month_use = {}
        for i in range(1, len(valid)):
            t_prev, n_prev, a_prev = valid[i-1]
            t_curr, n_curr, a_curr = valid[i]

            use_n = max(0.0, n_prev - n_curr)
            use_a = max(0.0, a_prev - a_curr)
            total = use_n + use_a

            # 归属月份
            month = t_curr.strftime("%Y-%m")
            month_use[month] = month_use.get(month, 0.0) + total

        # 3. 生成账单
        bill = []
        for m in sorted(month_use.keys()):
            bill.append(f"📅 {m}  总用电量：{month_use[m]:.2f} 度")

        # 4. 显示
        win = tk.Toplevel(root)
        win.title("月度账单")
        set_theme(win, settings.get("theme", "浅色"))
        text = tk.Text(win, font=("微软雅黑", 11), width=50, height=20)
        text.pack(padx=15, pady=15)
        text.insert("end", "\n".join(bill))

    # 快捷键
    try:
        keyboard.add_hotkey("ctrl+alt+q", do_query)
    except:
        pass

    # ========== 按钮 ==========
    ttk.Button(btn_frame1, text="🔍 一键查询", command=do_query, width=15).pack(side="left", padx=8)
    auto_btn = ttk.Button(btn_frame1, text="▶ 启动自动查询", command=toggle_auto, width=18)
    auto_btn.pack(side="left", padx=8)
    ttk.Button(btn_frame1, text="📈 用电图表", command=show_chart, width=15).pack(side="left", padx=8)
    ttk.Button(btn_frame1, text="📤 导出数据", command=export_data, width=15).pack(side="left", padx=8)
    ttk.Button(btn_frame1, text="📅 月度账单", command=show_month_bill, width=15).pack(side="left", padx=8)

    ttk.Button(btn_frame2, text="➕ 添加房间", command=add_room, width=15).pack(side="left", padx=8)
    ttk.Button(btn_frame2, text="🔄 刷新历史", command=show_history, width=15).pack(side="left", padx=8)
    ttk.Button(btn_frame2, text="🗑 清空记录", command=clear_history, width=15).pack(side="left", padx=8)
    ttk.Button(btn_frame2, text="💾 数据备份", command=backup_data, width=15).pack(side="left", padx=8)
    ttk.Button(btn_frame2, text="⚙ 设置中心", command=open_settings, width=15).pack(side="left", padx=8)

    # ========== 统计 ==========
    stats_label = ttk.Label(root, text="📈 用电统计", font=("微软雅黑", 12, "bold"))
    stats_label.pack(pady=(10,0))
    stats_text = tk.Text(root, width=90, height=3, font=("微软雅黑", 11), relief="flat", bd=2)
    stats_text.pack(padx=20, pady=5)

    # ========== 历史记录 ==========
    history_label = ttk.Label(root, text="📜 最近查询记录", font=("微软雅黑", 12, "bold"))
    history_label.pack(pady=(10,0))
    history_text = tk.Text(root, width=100, height=12, font=("微软雅黑", 10), relief="flat", bd=2)
    history_text.pack(padx=20, pady=5)

    root.mainloop()

if __name__ == "__main__":
    main_gui()
